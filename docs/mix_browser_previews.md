# MIX Entry Previews

The browser previews text documents, PCX images, TS/RA2 SHP animations, VXL models, Westwood/JASC/RIFF PAL palettes, WAV audio, and Bink video. SHP and VXL previews can use palettes from the current MIX, sibling files, or an optional RA2/YR game directory configured through **Palette Sources**. The game directory is scanned for loose palettes and palettes inside nested MIX archives; game assets are read in place and are not bundled with the application.

Files detected as MIX containers are opened in their own browser tabs rather than previewed as documents. In RA2/YR game data, `.mmx` and `.yro` are encrypted MIX-format containers. `.mmp` files are treated as PCX images when their content has a valid PCX signature.

## Tab and Preview Runtime

Tabs have a context menu for closing the clicked tab, other tabs, tabs to its right, or all tabs. Their widths are fixed to fit the widest top-level `.mix` filename in the configured game directory; names that exceed the available width are elided. The preview pane is constructed at application startup and reused by the first opened page.

Raster previews start at 100% when they fit and shrink to fit the preview viewport when they do not. VXL previews use the configured 20% default as an upper limit and shrink further when the viewport requires it. Switching tabs pauses any animation or media playback at its current position; returning to that tab resumes playback that was running. Only the active tab can play a preview, and background preview decoding uses the shared single-worker executor. Pending work for inactive tabs is canceled where possible.

## Automatic Palette Selection

The automatic selection stages are:

SHP assets in `cameo.mix` use `cameo.pal` when it is available.

1. **User Defined.** Evaluate palette-library rows in configured order. Each regular expression uses a case-insensitive `re.search` against the asset basename, including its extension; an unanchored expression can match part of the name. The first match wins. Blank and invalid expressions do not match; palettes with blank expressions remain available for manual selection.
2. **Game Rule.** Read loose `rules.ini`, `rulesmd.ini`, `art.ini`, and `artmd.ini` files and the same named files inside MIX archives, including nested MIX archives. Resolve rules by asset section name and Art resource references, including `Image`, `Buildup`, `BibShape`, active and idle animations, and special overlays. `rules.ini` animation references and `[Animations]` entries identify animation SHPs; particle `Image` references identify particle graphics; `[OverlayTypes]` and `[TerrainTypes]` identify terrain SHPs; weapon `Projectile` links identify projectile `Image` SHPs; `[VoxelAnims]` identifies unit-palette VXLs. `NewTheater` variants can link a theater-specific asset to its base section. Use the first applicable target source in this order: non-default `CustomPalette`; non-default `Palette`; enabled `AltPalette`; enabled `NewTheater`; enabled `AnimPalette`; enabled `TerrainPalette`; Cameo/AltCameo and `SidebarImage` links; `ICON`/`UICO` cameo defaults; then animation, building, terrain, or unit defaults inferred from Art fields and file type. Boolean flags accept `yes`, `true`, or `1`, case-insensitively. Once a source applies, lower-priority target sources are not tried.

   `CustomPalette` values `none` and `default` are ignored; other values replace `~~~` with the theater code and add `.pal` when needed. `Palette` values `none` and `default` are ignored. A `Palette` value ending in `.pal` is used as written; a base name tries the theater-suffixed name before the unsuffixed name. `NewTheater` maps second basename characters `A`, `D`, `L`, `N`, and `U` to Snow, Desert, Lunar, New Urban, and Urban. `G`, `T`, and unmapped letters use the selected theater. When Art resource references identify a concrete theater suffix, that suffix can select its corresponding palette. The preview theater is configured under **Palette Sources**; Auto defaults to `tem` (Temperate) when the entry does not identify a theater. Theater codes are `tem`, `sno`, `urb`, `des`, `lun`, and `ubn`. Boolean flags accept `yes`, `true`, or `1`, case-insensitively.

   Cameo and AltCameo references use `UnitArt.CameoPalette`, defaulting to `cameo.pal`. `SidebarImage` uses `SidebarPalette`, also defaulting to `cameo.pal`. Projectile rules with `FirersPalette=yes` use the firing unit's theater unit palette. Animation entries use `anim.pal` unless `AltPalette=yes` or `NewTheater=yes`. If an `AnimPalette` field is present but disabled and `TerrainPalette` does not match, the current rule logic returns the theater unit palette. Building art with a `Foundation` uses the theater building palette. Unit art identified by Art fields and VXL models use the theater unit palette. Theater-suffixed terrain SHPs use the matching theater palette. Resource basenames ending in `ICON` or `UICO` use the cameo palette defaults before category-based defaults.

If no explicit Art palette rule applies, smoke names containing `SMK`, names ending in `WAKE` or `LEAK`, and the `CHRONO` effect family use the animation palette. `S` and `Y` suffix variants of names listed as animations retain the animation palette category. SHPs with basenames ending in `WALL` use the selected theater's unit palette. The game marks its `GAWALL` and `NAWALL` Art entries as theater-aware, and `YGWALL`/`YAWALL` follow the same generic/theater-specific naming pattern.

Built-in UI SHP families use their dedicated game palettes: `arrow` uses `mousepal.pal`; `ebtn-dn` and `ebtn-up` use `sdbtnanm.pal`; `pipbrd`, `pips`, `pips2`, `progbar`, `progbar2`, and `progbarm` use `sidebar.pal`.

   Check only the expected name or names returned by the first applicable target source. For each name, compare palette basenames case-insensitively and check current-MIX/same-folder palettes before game-directory palettes. A local copy wins over a game-directory copy with the same basename, even when their colors differ. If several local palettes have that basename, choose the first in the local candidate order: case-insensitive full name, source, then color values. If that source's returned names are absent from both places, continue to inference instead of trying lower-priority target sources.
3. **Inference.** First compare the asset and palette basename stems for exact equality, case-insensitively, with no minimum-length requirement; check current-MIX/same-folder palettes before game-directory palettes. For SHP assets, a named non-ISO theater MIX supplies theater context when the filename and Art rules do not: `temperat`, `snow`/`snowmd`, `urban`, `desert`/`des`, `lunar`/`lun`, `urbann`, and `ubn` select that theater's unit palette. ISO MIX names select the corresponding ISO palette instead; `temp` and `snow` are aliases for `tem` and `sno`, while `isogen` and `isogenmd` use the configured theater (Auto defaults to `tem`). These archive-context matches follow exact basename matching. After exact basename and archive-context matches, a one-frame SHP with a 60 by 48 canvas is treated as a cameo and uses `cameo.pal` when available; this precedes prefix and similarity matching. If there is no exact or context match, compare filename prefixes: a palette stem must have at least 6 characters and prefix-match the asset stem. Within the current-MIX/same-folder group, the longest match wins; if there is no local match, apply the same rule to game-directory palettes. If no exact or prefix match applies, compare case-folded filename stems of current-MIX/same-folder palettes with Python's `difflib.SequenceMatcher.ratio`; choose the highest-scoring local palette only when its score is strictly greater than 70%. Break ties by case-insensitive palette name, source, then color values. If no local score is greater than 70%, compare game-directory palette stems with the same method and threshold, breaking ties by case-insensitive palette name, source, then color values. If neither similarity step matches, choose one current-MIX/same-folder palette deterministically by case-insensitive palette name, source, then color values. Do not choose an unrelated game-directory palette at this step.
4. **Fallback.** Select grayscale if no earlier stage found a palette.

The candidate list is separate from automatic priority. Its groups, each shown as a `- Group Name -` separator, are `Fallback` (grayscale), `User Defined`, `Same Directory` (current MIX and same-folder files), and `Game Directory`, in that order. Every discovered palette remains available for manual selection.

The palette behavior follows [Ares custom cameo palette rules](http://ares-developers.github.io/Ares-docs/new/customcameopalettes.html), [Ares animation and projectile palette rules](http://ares-developers.github.io/Ares-docs/new/customanimationandprojectilepalettes.html), and the documented [AltPalette](https://modenc.renegadeprojects.com/AltPalette), [AnimPalette](https://modenc.renegadeprojects.com/AnimPalette), and [TerrainPalette](https://modenc.renegadeprojects.com/TerrainPalette) flags.

The image and palette decoders are owned by the RA2AYRMB feature. The SHP and VXL parsers were implemented for this project; OpenRA's format readers were consulted for binary layout references only. No OpenRA implementation code or game assets are included:

- [OpenRA SHP TS reader](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Common/SpriteLoaders/ShpTSLoader.cs)
- [OpenRA VXL reader](https://github.com/OpenRA/OpenRA/blob/bleed/OpenRA.Mods.Cnc/FileFormats/VxlReader.cs)
- [OpenRA license](https://github.com/OpenRA/OpenRA/blob/bleed/COPYING) (GPL-3.0)

The preview controls are private to this browser feature. Their image fitting and palette-grid painting do not change the behavior of Qt's base controls elsewhere in the application.

The **Help > Preview Support...** command lists supported formats, file-size and decoded-image limits, supported XCC DAT data, and preview-specific limitations.

WAV and BIK/BK2 playback use libVLC 3.0.24 through `python-vlc`. Read and seek callbacks stream each entry directly from the MIX archive without extracting a temporary file. WAV media uses VLC's WAV demuxer; BIK/BK2 use the FFmpeg-backed VLC demux path. Media entries larger than 128 MiB are not previewed. The VLC runtime is prepared once with `tools/prepare_vlc_runtime.bat`; `package.bat` copies only the plugins listed in `tools/vlc_runtime_plugins.txt` and does not download the runtime again.

The `python-vlc` binding and libVLC retain their LGPL-2.1-or-later terms. The binary package includes the python-vlc `COPYING` file and VLC's GPL/LGPL license texts. The VLC runtime archive contains plugins and codecs under their own licenses. The selected plugin set and license findings are documented in `docs/vlc_runtime_licenses.md`. See the [Qt for Python license overview](https://doc.qt.io/qtforpython-6/licenses.html), [Qt open-source license obligations](https://www.qt.io/licensing/open-source-lgpl-obligations), and [VideoLAN downloads](https://get.videolan.org/vlc/3.0.24/win64/).

Raw 768-byte Westwood palettes have no identifying header. Unnamed entries of that exact size whose first 128 bytes fit the usual 6-bit palette range are treated as PAL candidates; this heuristic can still classify unrelated binary data as a palette. VXL previews build a bounded mesh from exposed voxel faces and render it with the Qt OpenGL APIs already included in the application environment. The default view uses an oblique -45-degree azimuth. Drag with the left mouse button to rotate, use the right or middle button to pan, and use the wheel or zoom controls to change scale. Reset returns to the default view and the requested 20% zoom. HVA transforms and limb animation are not evaluated, so multi-limb placement can differ from the in-game model. This feature adds no decoder package or third-party rendering source.
